# Внутреннее устройство компоненты

## Плата Lithography_board
Печатная плата Lithography_board используется для управление драйверами шаговых двигателей, светодиодами, и насосом, а также осуществляет опрос датчика температуры и давления. Плата была спроектирована в сервисе EasyEDA, производство печатной платы было осуществлено в компании Резонит, электронные компоненты для платы были заказаны преимущественно в магазине Чип и Дип или найдены на маркетплейсе OZON, монтаж электронных компонент осуществлял Банников М. И.

#### Демультиплексор PCF8575DW
Из-за ограниченного количества пинов платы ESP32 Wroom недостаточно, чтобы реализовать контроль над всеми периферийными устройствами. В этой связи некоторые функции контроля периферийных устройств переданы на демультиплексор PCF8575DW, который позволяет эффективно увеличить количество используемых пинов. Коммуникация с демультиплексором осуществляется посредством протокола i2c. Демультиплексор используется для управления пинами  enable и direction шаговых двигателей, а также для управления насосом.
